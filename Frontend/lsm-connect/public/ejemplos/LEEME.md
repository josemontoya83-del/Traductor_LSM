Videos OPCIONALES de ejemplo de una seña: `<tipo>_<id>.mp4`, p. ej. `sena_baja.mp4`.
Si existe, se muestra junto a la palabra durante la grabación.

Úsenlos SOLO para palabras ambiguas (que la persona no sepa qué seña se le pide). Si se pone
ejemplo en todas, todas las personas copiarán la misma variante y el modelo aprenderá menos
de cómo firma cada quien.
